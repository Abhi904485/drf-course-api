# DRF Course API

## Export Model Into Graph

```text
Note: Django Extensions are required or this 
python manage.py graph_models app_name > {file_name}.dot
EX: python manage.py graph_models api > api.dot

Install Graphviz Utility
brew install graphviz
EX:  dot -Tpng api.dot > output.png
REF: https://graphviz.org/doc/info/command.html
```
